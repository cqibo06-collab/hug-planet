# 拼豆图纸生成器 🧩 像素画工具

手绘像素画，或把照片一键变成拼豆图纸（含自动限色、用量统计、图纸导出）。纯网页，手机可用，可添加到手机桌面（PWA），数据自动保存在本机。

## 功能

- **手绘像素画**：画笔 / 橡皮 / 油漆桶填充 / 取色，撤销重做各 40 步
- **图片转图纸**：选一张照片 → 选板子尺寸（16~100）→ 拖动滑块限制最多用色数 → 自动缩小、按感知色差（Oklab）智能选色、匹配 48 色拼豆色板；多级缩小 + 锐化 / 自动对比度 / 提高鲜艳度 / **抖动过渡**（Floyd–Steinberg 误差扩散，渐变更细腻）/ **自动去背景**（只拼主体）/ **深色描边**（卡通图轮廓）
- **尺寸对比**：载入图片后自动排出一排不同格子数的成品对比卡（16~100，含用色数和豆子数），点哪个就用哪个
- **成品预览**：拖动滑块模拟"生豆 → 半融合 → 烫透"的烫后大致效果（实际成品取决于火候、豆子品牌和工艺）
- **成品预览**：拖动滑块模拟"生豆 → 半融合 → 烫透"的烫后大致效果（实际成品取决于火候、豆子品牌和工艺）
- **用量统计**：每种颜色要多少颗，一键复制购物清单
- **符号模式**：每格标注 A/B/C… 符号，黑白打印也能认色
- **导出**：图纸 PNG（带标尺），或保存工程 JSON 以后继续编辑
- **自动保存**：画的东西自动留在本机，关掉再开还在
- 标准板尺寸：16×16、29×29、40×40、50×50、58×58，另有 72×72（两块板拼）、100×100（大工程），改尺寸内容保留

## 电脑上预览

双击 `启动预览.bat`，或 `python -m http.server 8330`，打开 <http://localhost:8330>。

## 放到手机桌面

部署到任意静态托管（见下），手机浏览器打开网址：

- **iPhone（Safari）**：分享 ⬆️ → 添加到主屏幕
- **Android（Chrome）**：菜单 ⋮ → 添加到主屏幕 / 安装应用

## 部署到 GitHub Pages（同抱抱星球的方法）

1. [github.com/new](https://github.com/new) 新建仓库，如 `bead-pattern`，选 Public
2. 打开 `https://github.com/你的用户名/bead-pattern/upload/main`
3. 把本文件夹**里面的**内容拖进去（index.html、style.css、app.js、manifest.webmanifest、sw.js、icons 文件夹；gen_icons.py 和 bat 可以不传）
4. Settings → Pages → Branch 选 `main` + `/(root)` → Save
5. 访问 `https://你的用户名.github.io/bead-pattern/`

## 自定义

- **拼豆色板**：改 `app.js` 顶部的 `PALETTE`（48 个 `{n: 名称, h: 色号}`，是近似色，可按你手头豆子的实际色号微调）
- **符号表**：改 `SYMBOLS` 常量
- 改动后把 `sw.js` 里 `beadpattern-v1` 版本号 +1
