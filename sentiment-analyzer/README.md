# 心晴分析 🌦️ 中文情感分析器

输入一段文字，实时分析情绪倾向与构成。**方法学对齐学术标准**：情感词典法（软件学报 2010 综述路线）、七大情感分类与 1~7 级词强（大连理工情感词汇本体体系）、程度副词加权 + 否定词反转规则。

纯浏览器本地运行，不联网、不上传、无 API。

## 功能

- **单篇分析**：情绪分（-100~+100）+ 天气隐喻判定（☀️☀🌤️⛅🌧️⛈️）
- **情绪构成**：乐·快乐 / 好·喜爱 / 怒·愤怒 / 哀·悲伤 / 惧·恐惧 / 恶·厌恶 / 惊·惊讶 七类能量占比
- **关键词高亮**：红=消极 绿=积极 黄=程度词 蓝=否定词 紫=转折词
- **逐句分析 + 情绪轨迹图**：3 句以上的长文本按句打分并绘制情绪折线，起伏一目了然
- **转折加权**：但是/可是/然而/不过/却/但 后 50 字内的情感词权重 ×1.5（文献通用增强）
- **网络用语**：yyds、绝绝子、栓Q、emo、破防、拉胯、下头、社死、寄了、PUA…
- **对象情感（方面级）**：服务态度/味道菜品/价格/环境/物流/速度/质量 七类对象分别打分，双向条形图展示（"服务很好但菜难吃"不再是笼统一分）
- **人格画像（大五模型）**：开放性/尽责性/外向性/宜人性/神经质 五维雷达图 + 关键词标签；LIWC 式词频法（词表参考中文人格特质词研究）+ 行为信号（提问/感叹/人称/消极占比）；对话模式下每个说话人各自生成画像标签
- **说话人情感**：自动识别两种对话格式——"昵称：内容"同行式，以及微信合并转发的"昵称行/时间行/内容行"块式，按人分组独立分析（每人情绪分、主导情绪、消息条数、人格标签）；自定义表情占位符如[坏笑]自动剔除
- **聊天记录清理**：一键剥离微信粘贴文本中的时间戳、[图片][表情]占位符、合并转发头（对话模式自动保留昵称前缀）
- **批量分析**：每行一条，一次分析整批评论/弹幕/问卷，汇总积极/中性/消极数量、平均分、最极端条目，一键复制成表格
- **自定义词典**：`词语 ±强度` 每行一条，教它认识你自己的圈子（存在本机）
- **历史记录（隐私优先）**：**默认不保存**任何分析内容；明确开启后才写入本机浏览器 localStorage，保留 30 天自动清理，可逐条删除或一键清空，绝不联网上传

## 隐私与合规边界

- 页面零外部请求：无 CDN 脚本、无统计服务、无日志上报，所有计算在浏览器内完成（可用开发者工具 Network 面板审计）
- 分析结果仅供个人参考，**不构成心理诊断**，请勿用于评价员工/学生等自动化决策或筛选（参见《个人信息保护法》第 24、28-30 条）
- 若未来面向他人提供服务，需另行明确处理目的、保存期限与删除方式，遵循最小必要原则（第 6、17、19 条）；"本地运行"不豁免这些义务
- 不包含读取聊天记录、绕过平台权限或任何监控功能；分析的内容请确保是你有权处理的

## 分数与百分比说明

- 情绪分范围 -100 ~ +100：词典权重求和 → tanh 压缩 → 按命中数量折减置信度（单词不足以支撑极端判定）
- 情绪构成百分比 = 各情绪词典命中权重占比，非测量值
- "中性"（正负相抵）与"未识别到情绪"（零命中）是两种不同状态
- 反讽：同句"可真/真是+褒词"与贬词共存时提示疑似反讽并按反话处理，可一键切换按字面理解

## 算法说明

```
情感分 = Σ 情感词(强度1~7 → ±2) × 程度副词权重 × 否定反转(奇数次取反) × 转折加权(但后×1.5) + 表情分值
总分 = tanh( Σ情感分 × 感叹号增强 / (0.9×能量 + 1.5) ) × 100
```

- 程度副词五档：极其/万分(×2) … 非常/十分(×1.75) … 很/蛮(×1.5/1.4) … 比较(×1.3) … 有点/稍微(×0.6/0.5)
- 否定词：不/没/别/无/非/未…（自动剔除与程度词、转折词重叠的误匹配，如"非常"里的"非"、"不过"里的"不"）
- "惊讶"类词极性为 0：计入情绪构成但不左右好坏判断

## 部署 / 添加到手机桌面

与"抱抱星球""拼豆图纸生成器"相同：整包上传到 GitHub 仓库子目录（如 `sentiment-analyzer/`），Pages 自动发布；手机浏览器打开后"添加到主屏幕"即是全屏 App，离线可用。

## 自定义词典

`app.js` 顶部 `RAW` 对象按七类情感组织，格式 `"词语": 强度(1~7)`，直接增删即可；`DEGREES` 与 `NEGATIONS` 分别是程度副词权重表和否定词表。改完把 `sw.js` 里 `xinqing-v1` 版本号 +1。
