这是一个「空壳」面板：导入你自己的活动数据 JSON 后才会显示内容。
每个人导入各自的文件，数据只存在各自的浏览器里 —— 互相看不到，也不会上传到任何服务器。
🔄 还没有数据文件？装一个「书签」一键从到梦空间抓取
① 把这个链接拖到浏览器书签栏（或右键 → 添加到收藏）：
🪐 到梦空间 → 面板数据
② 打开并登录 www.5idream.net（到梦空间网页版，任意页面都行）；
③ 点书签栏里的「🪐 到梦空间 → 面板数据」——自动抓取你的活跃任务，下载 dmkj_panel_data.json；
④ 回到本面板点「导入」选文件（或「从剪贴板导入」）。
手机浏览器不方便装书签：在电脑上把 JSON 抓好后发给手机，或直接用文件导入。抓取只在到梦空间网页本身进行，不经过任何第三方。
没有数据文件？在 ZCode 里说「刷新活动面板」即可从到梦空间网页版导出一份。
面板只读展示快照，报名 / 签到 / 提交仍以【到梦空间 APP】为准。
