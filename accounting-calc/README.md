# 初级会计计算工具

一个纯前端的计算器合集，覆盖《初级会计实务》和《经济法基础》里**真正需要动笔算**的考点。

## 怎么用

**双击 `index.html` 就能打开**，不需要装任何东西，也不需要联网。

左侧选模块 → 右侧填数字 → 点"计算"。每个模块都会给出三项：

1. **结果**：核心数字；
2. **计算过程**：分步列出来，能直接抄到答题卷上；
3. **会计分录**（部分模块）：借什么贷什么，金额多少。

输入框已预填一组示例数据，打开就能看到算出来的样子。

## 模块清单（17 个）

依据 **2026 年度初级会计专业技术资格考试大纲**中标注"掌握"的考点整理。

### 资产核算（实务）
| 模块 | 覆盖考点 |
|---|---|
| 存货发出计价 | 先进先出法 / 月末一次加权平均法 / 移动加权平均法 |
| 固定资产折旧 | 年限平均法、工作量法、双倍余额递减法、年数总和法 |
| 无形资产摊销 | 直线法摊销 |
| 坏账准备 | 余额百分比法、账龄分析法（倒挤本期计提数） |
| 存货跌价准备 | 成本与可变现净值孰低、转回 |
| 材料成本差异率 | 计划成本法下的差异分摊 |
| 交易性金融资产 | 取得、公允价值变动、出售的损益计算 |

### 成本核算（实务）
| 模块 | 覆盖考点 |
|---|---|
| 约当产量比例法 | 完工产品与月末在产品之间的费用分配 |
| 辅助生产费用分配 | 直接分配法、交互分配法 |
| 本量利分析 | 保本点、安全边际、目标利润销量（2026 大纲未单列，作拓展） |

### 税法计算（经济法）
| 模块 | 覆盖考点 |
|---|---|
| 增值税 | 一般计税、简易计税、进口与视同销售的组成计税价格 |
| 消费税 | 从价 / 从量 / 复合，自产自用 / 委托加工 / 进口的组成计税价格 |
| 企业所得税 | 业务招待费、广宣费、公益捐赠、三项经费的扣除限额与纳税调整 |
| 个人所得税 | 综合所得年度汇算、工资薪金累计预扣法 |
| 小税种速算 | 城建税及附加、印花税、房产税、土地增值税、契税、车辆购置税、关税、城镇土地使用税 |

### 劳动法计算（经济法）
| 模块 | 覆盖考点 |
|---|---|
| 经济补偿金 / 赔偿金 | N、N+1、2N，三倍工资封顶与 12 年封顶 |
| 加班工资 | 150% / 200% / 300%，月计薪天数 21.75 |

## 想加一个自己的模块

只要在一个新文件里调用 `App.register()` 就行，框架会自动把它挂到侧边栏：

```js
App.register('资产核算', {
  id: 'my-module',
  name: '我的计算器',
  tip: '一句话说明这个模块算什么',
  inputs: [
    { key: 'a', label: '第一个数', value: 100, unit: '元' },
    { key: 'mode', label: '方式', type: 'select',
      options: [{ v: 'x', t: '方式一' }, { v: 'y', t: '方式二' }] },
    // 只在某些情形下才显示的字段：
    { key: 'b', label: '第二个', value: 0, showIf: function (v) { return v.mode === 'x'; } }
  ],
  compute: function (v) {
    return {
      result: [{ k: '结果名', v: App.money(v.a * 2) }],   // 顶部大字结果
      steps: ['第一步 = ...', '第二步 = ...'],              // 计算过程
      tableHtml: App.table(['列1', '列2'], [['a', 'b']]),   // 可选明细表
      entry: ['借：xxx  100', '    贷：yyy  100'],          // 可选会计分录
      note: '易错提示'                                       // 可选黄色提示框
    };
  }
});
```

新文件写好后，在 `index.html` 里加一行 `<script src="assets/你的文件.js"></script>` 即可。

可用工具函数：`App.fmt(n)` 千分位、`App.money(n)` 加 ¥、`App.pct(n)` 加 %、`App.table(head, rows)` 生成表格、`App.progressive(金额, 税率表)` 超额累进。

**改完之后跑一下自检：**

```bash
node smoke-test.js
```

它会遍历每个模块的每种选项组合，检查有没有报错、NaN 或空结果。

## 说明与提醒

- 税率和扣除比例按 2025—2026 年现行政策设置，**考试前请以当年教材为准**（尤其是专项附加扣除标准和小微企业优惠，这两块调整较频繁）。
- 所有计算都在浏览器本地完成，不上传任何数据。
- 若要把它变成可以装到电脑上的 exe，可以直接复用同目录下的 `HtmlApp` 模板：把 `index.html` 和 `assets` 拷进它的 `web` 文件夹即可，改页面不用重新打包。
