# 刷题助手 📝

单文件、零依赖、纯离线的本地刷题应用：粘贴题目 → 练习/考试 → 错题本 + 知识点掌握度分析。

## 使用方式

- **在线使用**：<https://cqibo06-collab.github.io/hug-planet/brush-quiz/>
  （手机浏览器打开后可「添加到主屏幕」当应用用；数据存在浏览器本地）
- **本地使用**：双击 `index.html` 即可，无需联网、无需服务器。
- **完整说明书**：打开 `说明书.html`（导入格式、五种题型、知识点体系、备份恢复、FAQ 全在里面）。

## 功能清单

- **五种题型**：单选 / 多选 / 判断 / 填空 / 简答，可自动推断也支持显式标记
- **导入**：粘贴文本（宽松解析，兼容全角编号、无题号、答案写在行尾等几十种写法）、txt/md/csv/json、ZIP 题图包、手动录入
- **两种模式**：练习（即判 + 解析）/ 考试（交卷统一判分 + 倒计时）
- **错题本**：间隔复习（1/3/7 天）、连续答对自动出本、错因分类
- **知识点体系**：树形知识点、题目关联权重、掌握度公式可解释、薄弱点推荐、每周复盘
- **备份**：每次导入自动快照，支持导出/导入全量备份（覆盖 / 合并两种恢复）

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 发布版（压缩单文件，平时用这个） |
| `index.dev.html` | 开发版源文件（带注释缩进，改代码改这个） |
| `build.js` | `node build.js` 从 dev 版生成发布版 |
| `说明书.html` | 完整使用说明书（可打印成 PDF） |

> 注意：题目、错题、记录全部存在浏览器本地（IndexedDB，失败自动回退 localStorage），
> 换设备或清浏览器数据前记得先用「备份」导出一份。
