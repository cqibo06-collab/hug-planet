支持 .txt / .md / .csv / .json，可多选：一次选中全部 Java2_第X章.json 会分别建题库，也可选「合并成一个题库」。

ZIP 题库包（推荐给手机端）：直接选一个 .zip，里面可以同时装多个 JSON 题库、题图、知识点文件，系统会一次性全部导入并自动把题图关联到对应题目。建议结构：

Java题库.zip
├─ Java2_第1章.json        ← 每个 JSON 建一个题库（也可用 { banks:[...] } 一次装多套）
├─ Java2_第2章.json
├─ images/xxx.png          ← 题图，JSON 里写 "image":"images/xxx.png" 或只写 "xxx.png" 都能配上
└─ 知识点.json              ← {"pts":[...],"qlink":{...}}，合并进现有知识树

题图：JSON 里写 "image": "图片名.png" 或 "images": ["a.png","b.png"]。若不用 ZIP，就把图片放在本页 index.dev.html 旁边（或子文件夹里写相对路径）；也可以在题目编辑器里直接上传本地图片（会存成 base64，不怕路径错）。ZIP 包里的图片会自动转成内嵌 base64。

这块卡片支持三种投喂方式：① 把文件拖进来（整包 ZIP 也行）；② 复制文件后在本页按 Ctrl+V 粘贴； ③ 点上面的「选择文件」。三条路任选，哪条顺手用哪条。 若三条都没反应，多半是当前窗口把文件选择拦住了 —— 用 Chrome / Edge 双击打开本页， 别在应用内置的预览窗（或微信内置浏览器）里点。
