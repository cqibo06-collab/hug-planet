0速览与三分钟上手

它不是一个「随便抽题给你做」的刷题器，而是一个小型学习诊断系统： 录入知识结构 → 导入题目并关联到知识点 → 做题与自测产生记录 → 系统算出每个知识点的掌握度 → 给出带理由的复习建议 → 你照着做 → 产生新记录。闭环就是这样转起来的。

它擅长的

  • 把 Word / PDF / 学习通里复制出来的一大坨题目整理成题库
  • 练习与考试两种节奏，自动收错题
  • 按知识点而不是按题库统计掌握度
  • 区分「不会」和「会但做错」
  • 告诉你为什么推荐这一步，以及今天做不完的部分

它不做的

  • 不联网、不上传、没有账号
  • 不自动判简答题（只做左右对照）
  • 不替你判断「会不会」，只根据你留下的痕迹估
  • 不提供课程视频/讲义内容本身

一句话定位

把「我到底哪里不会」这件模糊的事，拆成一组能看见、能追溯、能按天安排的数字。

三分钟上手

  1. 导入题目：进「导入题目」，把题目原文粘进文本框 → 点「解析文本」→ 在预览表里检查/改几道 → 建库。
  2. 录入知识点（强烈建议，别跳过）：进「知识点」，每行一个，用 > 表示层级，例如 数据结构 > 线性表 > 单链表头插法。
  3. 关联：回到「题库 → 查看/打标签」，单题点 🔗 关联知识点；或点「按名称/标签自动关联题目」让系统先配一遍，你再修。
  4. 开始练：首页选择题库 → 练习模式。做完记得选一下信心程度，答错记得点错因。
  5. 看建议：知识点页的「今日建议」会给出带理由的任务清单，点「开始」直接跳到对应动作。
只有第 1 步也能用（当普通刷题器）。但从第 2 步开始，它才真正变成「诊断系统」—— 掌握度、推荐、周复盘全部建立在知识点之上。

2导入题目

① 粘贴文本（最常用）

直接从 Word / PDF / 学习通复制，粘进去点「解析文本」。解析器很宽松：全角编号、Ａ． 这类全角选项、 答案写成「答案：A」「【答案】A」「正确答案 A」、题干和选项挤在同一行、PDF 断行——都能处理。

1. 下列关于函数的说法正确的是（ ）
A. 选项一
B. 选项二
C. 选项三
D. 选项四
答案：A
解析：略

2. 【多选题】下列哪些属于…（ ）
A. …
B. …
答案：AB

3. 判断题：地球是圆的。
答案：对

题型会自动推断；也可以写 【单选题】 【多选题】 判断题： 这类显式标记强制指定。 填空题多个空用 | 分隔。

简答题怎么导（这块规则最多）

下面这些写法都认，答案行的开头可以是：

答案： 参考答案： 正确答案： 标准答案： 答案要点： 解答： 答：——后面跟冒号、破折号，或者什么都不跟都行。

6. 死锁的四个必要条件是什么？
参考答案：
1. 互斥条件
2. 请求与保持条件
3. 不可剥夺条件
4. 环路等待条件

7. 谈谈你对时间复杂度的理解。   ← 没写参考答案也能导进来，做题时自评
  • 分条写的答案不会被撕成好几道题，换行会原样保留，看的时候还是四条。
  • 没有参考答案的简答不会被当成"缺答案"丢掉，预览里标注「无参考答案 · 自评」。
  • 答案解析： 算解析，不会混进答案里。
  • 试卷里「一、简答题（每题 10 分）」这种大标题会被跳过，但它会告诉系统——后面这一段默认是简答题。
  • 做题时简答题不自动判分、也不计入得分分母，交卷后左右对照自评，不会拉低你的分数。

答案没写在「答案：」那一行也能认

写法例子
跟在题干行尾1. 以下哪项不属于操作系统？（　）（答案：C）　或　…。答案：并发、共享
写在题干括号里1. 操作系统的主要功能是（ B ）
正确选项后打勾B. 磁盘驱动器 √
选项之后孤立一行四个选项下面单独一行写 A 或 ABC
判断题末尾画圈进程是程序的一次执行过程（√）

题号 / 分隔方式：怎么排都行

  • 编号认这几种：1. 1、 1） (1) 第1题 【1】 一、，Markdown 的 ## 1. 也认。
  • 完全没有题号也行：题目之间空一行；就算没空行，只要「下一组选项」出现就能自动断开。
  • --- 这类分隔线、【单选题】 这类题型标签，都会被当作题与题的边界。
  • Word / Excel 表格粘出来的一行（Tab 分列）、四个选项挤在一行的 PDF 文本，都能直接贴。
  • 「一、单选题（每题 2 分）」这类章节大标题不会变成一道题，而是给后面一段定默认题型。

② 上传文件（可多选 / 可 ZIP 整包）

支持 .txt .md .csv .json .zip，可以一次选中十几个章节文件： 每个文件单独建题库，也可以合并成一个。可勾选「用文件名给题目打标签」。

三种投喂方式（任选，哪条顺手用哪条）

  • 选择文件：点输入框选，可按住 Ctrl / Shift 多选。
  • 拖进来：把文件（或整包 ZIP）直接拖到「②上传文件」这块卡片上，卡片会变色并提示「松手就导入」。
  • Ctrl+V 粘贴：在资源管理器里 Ctrl+C 一个文件，回到本页按 Ctrl+V； 手机上「拷贝 → 粘贴」同样好使。
三条通道都给同一条导入流水线，结果完全一样。如果三条都没反应，是当前窗口把文件选择拦住了 —— 用 Chrome / Edge 双击打开这个 HTML，不要在应用内置的预览窗、或聊天软件内置浏览器里点。 （拖拽和粘贴在部分内置浏览器里仍可用，可以先用它们顶上。）

ZIP 题库包（推荐给手机端）

Java题库.zip
├─ Java2_第1章.json        ← 每个 JSON 建一个题库（也可 { banks:[...] } 一次装多套）
├─ Java2_第2章.json
├─ images/xxx.png          ← 题图，JSON 里写 "image":"xxx.png" 或 "images/xxx.png" 都能配上
└─ 知识点.json              ← {"pts":[...],"qlink":{...}}，合并进现有知识树

解压是自己实现的、零依赖的（支持 store 与 deflate 两种压缩方式），包里的图片会自动转成内嵌 base64 并绑到对应题目上 —— 手机上不用再一个个点文件，也不用担心图片路径失效。

题图的三种写法

  • ZIP 包内：JSON 里写 "image":"images/xxx.png"（写单纯文件名也能配上），导入时自动内嵌。
  • 相对路径：把图片放在网页文件旁边或子文件夹，JSON 里写相对路径。
  • 直接内嵌：在题目编辑器里上传本地图片，存成 base64，最稳，代价是备份文件变大。
只放行 http(s) / data:image / blob / 相对路径，javascript: 之类会被直接挡掉。

③ 手动添加单题

页面最下方的表单，选题型、选归属题库、填题干选项答案即可，适合补那种导入时漏掉的题。

导入后的两道保险

校验报告

统计总题数、题型分布，并标出：缺答案、缺选项、答案不在选项里、题干过短、重复题、带图题、含代码题。 有问题的题不会丢，会打上标记留在可编辑预览里等你改。

去重

按「题干 + 选项」指纹比对，同时去掉批内重复和与已有题库重复的题， 导入完成会提示「新增 N，跳过重复 M」。可在设置或批量面板里关掉。

3刷题：练习与考试

模式行为适合
练习选完立即判分并显示解析（可关）；答错当场进错题本；可以慢慢想，看本题已练次数与正确率。平时推进、啃新内容
考试全部答完交卷后统一判分，可设倒计时（分钟，0 为不限时）；交卷后逐题回看。自测、模拟、限时训练

组卷（练习 / 考试 / 混合组卷共用）

一个弹窗里同时决定：题库（可多选）→ 知识点（可多选，含下级）→ 标签/章节 → 题型 → 题目来源（全部 / 只刷错题 / 只刷未做 / 只刷收藏）→ 错题优先比例（0~100%，其余用新题补足）→ 题量 → 顺序（随机 / 原顺序）→ 模式与倒计时。筛选过程中实时显示「匹配 N 题」。

想突击某一章：知识点选那一章 + 来源选「只刷未做」+ 题量 20。 想清错题：来源「只刷错题」并直接点错题本的「重做错题」（只出不待掌握的那些）。

答题页

  • 右侧答题卡：跳题、看已答/未答、标记本题、☆ 收藏。
  • 题干支持图片与代码块：代码题会自动识别成等宽块（支持 ``` 围栏，也能自动识别连续代码行），带一键复制、超 18 行折叠。
  • 答案对比区左右两栏对照（填空/简答尤其有用）。简答题不自动判分，也不计入得分分母 —— 避免把分数拉低。
  • 题目下方会显示它计入哪些知识点，随时知道这一题在给谁投票。

4信心程度：答对 ≠ 会

每答完一题，页面会请你标一下当时状态（结果页也能回头补）：

选项权重系统怎么理解
确定会1.0独立、稳定地答出来，这是最硬的证据。
有点犹豫0.7答对了但不够稳，仍然计入，只是分量打折。
靠猜0.3答对也自动进错题本（标注「蒙对」），不算掌握。
不会0等同于没掌握，先从知识卡补起。
两个反直觉但重要的处理：
① 答对但靠猜 → 直接进复习队列，别被正确率骗了。
② 答错但当时「确定会」 → 归为表现型失误（审题/计算/表达），不是知识漏洞，推荐的是限时训练而不是回去看书。
如果你后来改口说「其实确定会」，那条蒙对记录会自动撤销。

权重会乘进单题贡献里的「独立完成度」一项，进而影响掌握度。觉得它太狠或太松，可以直接改脚本里的 CONF 表。

5错题本与错因

间隔复习节奏

答错后按 1 天 / 3 天 / 7 天 的间隔提醒重做；答对升一级，答错回到第 0 级。 错题本默认显示「今天该复习」的那些，其余有倒计时提示。

掌握规则（什么时候算真会了）

连续答对 2 次（设置里可改成 3 次）且两次间隔 ≥ 1 天 —— 同一天连做三遍对不算，那是短时记忆。 达标后自动移到「已掌握」，不再占「重做错题」的名额；想再练可手动「重新复习」。

错因：把「错了」翻译成「下一步做什么」

知识型（know）

概念不清 · 定义/公式没记住 · 条件判断错 · 方法选择错 · 蒙对的
→ 建议：回知识卡与问答自测，不要急着刷同类题。

表现型（perf）

审题/粗心 · 计算失误 · 表达不完整
→ 建议：限时训练 + 步骤复盘，知识点本身没问题。

这个分类直接决定推荐引擎给你「看知识卡」还是「练这里的题」，也是周复盘里「知识型 vs 表现型」统计的来源 —— 不标错因，复盘就缺一半信息。

6知识点体系

录入

每行一个，用 > 或缩进表示层级，父级会自动创建：

数据结构 > 线性表 > 顺序表的插入删除
数据结构 > 线性表 > 单链表的头插法
数据结构 > 栈和队列 > 栈的应用：括号匹配
操作系统 > 进程管理 > PV 操作

两个偷懒入口：从题库标签生成知识点（你之前拿标签当章节用的话，一键升级）、 按名称/标签自动关联题目（按关键词自动配对，你再修）。

关联题目

  • 单题关联：题库详情里每道题的 🔗 关联知识点，可多选、可设权重。
  • 批量关联：筛完条件后点「关联知识点」，一次给几十道题挂上。
  • 一题可以挂多个知识点并分别设权重 —— 一道综合题既考「栈」又考「递归」，两边都要投票。
关联单独存在一张 qlink 表里，不写在题目对象上。好处：题目怎么复制、导出、合并都不丢关联，也能批量改。

知识卡与问答自测

知识卡（note）

定义 / 要点 / 常见误区 / 前提条件。复习时先唤醒「这是什么」，不直接做题。

问答卡（cards）

问 + 要点，自评「答得出 / 答不出」。测的是不看资料能不能提取出来 —— 跟会做题是两回事。

自测结果会写进带时间戳的流水，直接进入掌握度计算（见下一节）。连续答不出时，系统会明确告诉你： 「提取不出来，不是不会做题，先看一遍知识卡，连续答对两次才算过。」

版本、健康状态与变更记录

  • 每个知识点记着创建时间、最后修改时间，以及变更记录（创建 / 修改 / 关联 / 合并 / 删除）。
  • 健康状态一眼看完：是否已关联题目、有无问答卡、有无知识卡内容、是否已有学习记录。
  • 可以设前置知识点：前置没掌握会成为推荐它的理由之一。
  • 反复合并拆分是常态，所以有 合并到…：把题目关联、问答卡、前置关系一起迁到目标知识点，源节点删除，并留一条变更日志。

7掌握度怎么算（以及为什么它标着「证据不足」）

单题贡献

原始分 = 0.28×历史正确率 + 0.18×最近是否答对 + 0.24×熟练度 + 0.15×稳定性 + 0.15×独立完成度
熟练度     = min(1, 练过次数 / 3)
稳定性     = 不在错题本 1.0 / 已修正 0.7 / 未修正 0
独立完成度 = 由你标的信心程度换算（见第 4 节）
贡献分     = 原始分 × 遗忘衰减， 衰减 = 1 − min(0.5, 距上次天数 / 40)

知识点得分

题目标现 = 100 × Σ(贡献分 × 权重) / Σ权重  −  min(20, 未修正错题数 × 5)
问答表现 = (0.35×自测正确率 + 0.25×最近三次 + 0.25×覆盖度 + 0.15×次数充足度) × 衰减
           连续答不出 ≥2 次 → 再打 0.7 折

两类证据都有 → 掌握度 = 0.7 × 题目标现 + 0.3 × 问答表现
只有一类     → 就用那一类（不做惩罚，缺证据不等于低分）

父节点知识点：自己没直接挂题就只由子节点聚合，不会因为自身 0 分把均值拉偏。

证据等级：分数旁边那行小字更重要

标记大致条件该怎么用这个分数
未关联题目没挂题、也没问答卡分数无意义，先去关联题目或补卡。
证据不足只做过一题、样本极少只能当参考，不当结论。
初步估计练过几题，样本还不够稳方向可信，具体数值别较真。
较可信证据量足够可以用来决定复习优先级。
稳定掌握多次答对、近期复习过、无未修正错题低频维护即可；超过 21 天没碰会自动降级。
这是整个系统里最容易误读的地方：0 分通常只表示「还没练过」，不表示「完全不会」。 所以分数后面永远跟着证据等级，鼠标悬停能看到具体说明。

所有权重都是经验值，不是常数真理。用一阵子觉得「问答的分量太轻/太重」，改 ptMastery() 里那两个系数就行。

8今日建议与学习目标

学习目标（先告诉系统你要什么）

知识点页顶部的目标卡，六项：

  • 主攻课程/范围：选一个知识点，它的整棵子树享受优先级加成。
  • 考试/作业日期：进入倒计时，临近时冲刺权重上升。
  • 每天可用时长（默认 60 分钟）：决定今天给你排多少任务。
  • 今日目标：查漏补缺 / 巩固 / 预习 / 冲刺 —— 分别偏向「最低分知识点」「中档 50~85 转稳定」「完全没练过的新点」「错题与主攻薄弱点」。
  • 想做题还是先理解：影响任务排序（先理解 → 知识卡和自测排前面）。
  • 期望复习间隔（默认 7 天）：超过就认为存在遗忘风险。

建议长什么样

每条推荐由三部分组成：知识点 + 一排理由 + 一串任务。理由是结构化的，不是「因为薄弱」这种废话，而是：

方法重写 vs 重载　掌握度 34%（证据不足）

最近两次答错 最近错因是「方法选择错」（知识型） 有 2 道错题还没修正 是「多态」的前置 在主攻范围内

任务：看知识卡 4 分钟 → 问答自测 6 分钟 → 修正错题 6 分钟 → 练这里的题 12 分钟　合计 28 分钟　[开始]

排序依据（优先级打分）

掌握度缺口 45 + 遗忘风险 25 + 未修正错题 20 + 未练习比例 10，再叠加：问答连续答不出、前置未掌握、主攻范围加成、考试倒计时加成、今日目标权重。 任务按分钟数估时，超过今日预算的部分会明确标出来，不会假装你做得完。

连续两次答不出问答卡时，任务会以「知识卡 + 自测」开头，而不是继续推题 —— 提取不出来的时候，刷题只是在浪费时间。

9每周复盘

「学习记录」页的周复盘不重复罗列数字，而是回答四个问题：

  1. 本周哪些知识点提升了 —— 与上周对比，掌握度上升的点。
  2. 哪些退步了 —— 下降的点，多数是遗忘，提醒你补一次。
  3. 哪些在反复错 —— 同知识点、同题目反复失手，说明方法不对，不是练得不够。
  4. 错误性质 —— 知识型 vs 表现型的比例。

最后给出下周怎么调整，是具体动作而不是口号，例如：

知识型错误占多数 → 减少盲目刷新同类题，先回知识卡和问答自测，答得出来再去做题。

结论可以一键复制，直接贴进你的周计划或日记。所有统计都来自带时间戳的作答流水，可追溯到具体哪一次。

恢复的两种方式

  • 覆盖：以备份为准，恢复前会先自动备份一次当前数据。题目 id 会被重建，系统会把 qstat / qlink / 收藏 / 错题 / 记录 的引用全部重映射 —— 这是修掉的老 bug，覆盖恢复后掌握度不再归零。

13常见问题

选了文件没反应，框里还是「未选择文件」？

这是曾经真实存在的 bug（现已修好）：读文件前先清空了输入框，而 input.files 是「活」的列表， 一清空连文件一起没了，于是导入流程根本没被触发，界面也毫无反应。 现在换成了三条通道（选择文件 / 拖拽 / 粘贴），任何一条成功都会有明确反馈：出现「已选择 N 个文件 · 共识别 M 题」的面板，或者一张写明原因的失败卡片。 如果三条都没反应，就是窗口层面的限制，换浏览器打开本页。

为什么我导入的题乱七八糟？

先看校验报告：缺答案、答案不在选项里、题干过短都会被标出来，在预览表里直接改。 最常见的原因是 PDF 复制时选项和题干粘成一行，或者答案行格式太怪 —— 这两种解析器都做了兜底，还是不行就手动改那几道。

掌握度为什么一直是 0？

八成是题目没关联到知识点。掌握度是按知识点算的，没关联的题不参与。 去题库详情点「关联知识点」，或点「按名称/标签自动关联题目」先自动配一轮。

0 分是不是说明我完全不会？

不是。看分数旁边的证据等级：写着「未关联题目」或「证据不足」，说明只是没数据。 系统刻意不把「没练过」显示成「不会」。

为什么推荐让我看知识卡，而不是多做题？

因为你在这个点上的错误是知识型的（概念/条件/方法），或者问答自测连续答不出来 —— 意思是「提取不出来」，此时刷题只是在反复暴露同一个洞。看懂 → 答得出 → 再做对，这个顺序更快。

为什么我的简答题导进来是空的 / 少了一堆？

以前有两个坑（现已修好，供你判断是否还遇到）：一是答案开头写「答：」时不识别，整段被当成题干；二是答案里带 1. 2. 编号会被当成新题切开，一道题变成一道"缺答案"的垃圾题。现在的规则见上一节。

简答题不给我判分？

故意的。自动判简答要么太宽松要么太离谱，所以简答题不计入得分分母，只在结果页给你左右对照自己看。

图片在别的电脑打不开？

用相对路径就会这样。要么放进 ZIP 包一起导入（自动转内嵌 base64），要么在题目编辑器里直接上传图片。

数据会不会被传到网上？

不会。整个文件没有一行网络请求代码，断网也能用。唯一的例外是你自己引用了外链图片。

14它的边界（请认真读完这一段）

  • 掌握度是估计，不是测量。它只反映你在这个题库、这些题上留下的痕迹。题库覆盖不到的地方，系统看不见。
  • 推荐只负责排序，不负责判断对错。你比它更清楚明天考什么 —— 把推荐当参谋，不当指令。
  • 「会做题」和「懂了」是两件事。所以才同时看题目表现和问答表现：前者是应用，后者是提取。
  • 证据不足时，任何分数都别当结论。样本少的知识点，宁可多练两道再看。
  • 它不会替你学。录入知识点、标错因、标信心——这三件事你不做，系统就只剩一堆正确率。
  • 数据没有云端。换设备、清缓存都会丢，请养成导出备份的习惯。
最小可用原则：先让它跑起来（导入 → 练 → 看错题）， 等规则不够用了再加知识点、错因、目标。不要为了用满功能而用功能。
